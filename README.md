\# OpenClaw Control



Dashboard e agente de controle para OpenClaw.



\## Recursos

\- 🔐 Autenticação (admin)

\- 🌍 Multi-idiomas (pt-BR / en-US)

\- 📋 Kanban de tarefas

\- ⛔ Controle do Gateway OpenClaw

\- 📊 Dashboard modular

\- 🧩 Base pronta para SaaS



\## Requisitos

\- Node.js 20+

\- OpenClaw rodando localmente



\## Rodar localmente

```bash

npm install

npm start
